2.  ##### CI
    На каждый pull request (build -> lint/unit -> API/integration -> UI smoke -> deploy). Если smoke падает -> пайплайн красный -> release блокируется. QA разбирает падение, разработчик исправляет дефект. Если это флаки тесты, то отдельно создаётся задача на его исправление.
